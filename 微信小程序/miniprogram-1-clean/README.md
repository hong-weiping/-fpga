# 万达广场智慧管理小程序

## 导入工程
在微信开发者工具中选择“导入”，目录选择本文件夹，使用已配置的小程序 AppID。不需要安装 npm 依赖。

## 启动后端（当前方式）
本文件夹仅包含最终小程序工程。后端单独位于 `C:\wechat_devtools\wechat_projects\onenet-local-server-time-weather`。

打开 PowerShell，在同一个窗口依次执行：

```powershell
cd C:\wechat_devtools\wechat_projects\onenet-local-server-time-weather
$env:DEMO_ACCESS_TOKEN = '替换成你设置的后端访问口令'
powershell -ExecutionPolicy Bypass -File .\start-real.ps1
```

- 请替换命令中的口令占位文字，小程序连接时填写完全相同的口令。不要填写 OneNet 产品密钥或设备密钥。
- 忘记旧口令时可以设置新口令，并同步修改小程序里的口令。
- `DEMO_ACCESS_TOKEN` 只对当前终端及其子进程有效。关闭终端后，下次启动需要再次设置。
- 出现 `OneNet auto authentication enabled. No debug-token refresh required.` 表示已启用 OneNet 自动认证，不需要更新调试 token。若随后提示缺少 `DEMO_ACCESS_TOKEN`，说明后端还未启动，需设置上述访问口令后重试。
- 后端默认端口为 3000。启动后保持终端打开，按 Ctrl+C 可停止；修改配置后停止并重新执行上述命令。

## cpolar 公网连接（手机推荐方式）
1. 先启动上面的后端，再启动电脑上的 cpolar。打开本机管理页面 `http://127.0.0.1:9200` 并登录。
2. 创建或编辑 HTTP 隧道。本地地址填写 **`http://127.0.0.1:3000`**，不要填写 `https://127.0.0.1:3000`。本地后端提供 HTTP 服务。
3. 地区选择此前连接成功的 **China Top / cn_top**（以管理界面显示名称为准）。启动隧道，在“在线隧道列表”找到 HTTPS 公网地址。
4. 复制当前的 **`https://……cpolar.top`** 地址。不要使用管理页面的 9200 地址，也不要使用旧隧道地址；临时公网地址可能在重启后变化。
5. 在小程序底部打开“连接设置”，后端地址填写该 HTTPS 公网地址，访问口令填写启动后端时设置的 `DEMO_ACCESS_TOKEN`，点击“保存并连接”。
6. 使用期间保持电脑联网，后端和 cpolar 都运行。通过公网隧道连接时，手机不必与电脑处于同一局域网。

### 连接排查
- **提示“后端访问口令不正确”**：核对小程序口令和后端启动口令。浏览器直接访问受保护接口时没有携带口令，出现这个提示并不表示隧道故障。
- **HTTP 502**：确认后端已经启动，隧道本地目标为 `http://127.0.0.1:3000`，端口一致。
- **HTTP 404**：先从在线隧道列表重新复制当前地址，确认映射的是本后端，不要自行在小程序后端地址末尾添加接口路径。404 也可能是请求路径不存在。
- **电脑可用、手机不可用**：检查微信合法域名和手机调试设置。HTTPS 隧道不等于自动通过微信域名校验。
- 连接后端成功不代表 FPGA 在线，请查看数据更新时间和设备确认反馈。

### 可选：局域网直连
手机和电脑在同一可互访网络时，也可填写 `http://电脑当前IPv4地址:3000`，例如 `http://192.168.43.101:3000`。电脑防火墙需允许 TCP 3000 入站；热点或校园网可能隔离设备。手机不能用 `localhost` 或 `127.0.0.1` 访问电脑后端。

## 主要功能
- 室内温湿度、福州天气和北京时间。
- 音量、静音、上一张、下一张及自动播放。
- 手动亮度与环境光自适应。
- 寻人通知发布、取消及状态查询。
- 火灾提示、页面打开时震动、确认提醒。确认提醒不会解除现场火灾报警。

## 手机打开
开发者工具点击“预览”，微信扫码。局域网 HTTP 调试需按微信当前规则开启开发调试；开发者工具的“不校验合法域名”不会自动作用于手机。
比赛使用可上传后在微信公众平台设置体验版，并添加体验成员。正式使用需要配置有效的 HTTPS 后端和 request 合法域名。
小程序不会把电脑后端一起打包，使用时仍需保证后端运行且手机可访问。

## 文件结构
- app.js / app.json / app.wxss：应用入口、配置和全局样式。
- pages/index/：主页面及控制交互。
- utils/api.js：后端 HTTP 请求。
- utils/environment.js：时间和天气显示。
- project.config.json：微信开发者工具工程配置。
- sitemap.json：页面索引配置。

本精简版保留现有功能代码，未包含历史备份、未使用的日志页和模板工具文件。后端地址和访问口令通过页面填写并保存在本机，不写入此说明。
